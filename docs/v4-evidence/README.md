# Historical local evidence

This directory contains diagnostics produced by an earlier constrained execution environment. It is preserved for audit history, but it is **not current release evidence** and must not be used to claim that production gates passed.

Current durable release evidence must be generated by `scripts/ci/generate-release-evidence.mjs`, tied to an exact Git commit and workflow run, and retained with the release artifact. See `docs/evidence/README.md`.
