# Repository rules

1. Scientific authority is explicit. Unsupported claims abstain.
2. `packages/genetics-core` stays pure, deterministic, and free of database, network, React, AI, and worker dependencies.
3. Never infer dominance from capitalization or silently replace unknown genotype input.
4. Parent direction is preserved in contracts even when a nuclear model is symmetric.
5. Authoritative workspace records are always scoped and audited.
6. Catalog seed records are draft evidence, not executable rules.
7. Completed simulation inputs/results and published catalog releases are immutable.
8. Generated code is changed through its source schema.
9. Add tests for every scientific invariant or defect fix.
