# Capsicum Genetics Evidence Catalog v0.1

This research seed dataset contains 22 curated Capsicum locus/model records, 22 atomic evidence claims, 30 publication/standard/resource records, a data dictionary, standards map, and a production-readiness backlog.

## Use

Use the workbook as the initial scientific catalog for a pepper breeding planner. It is deliberately conservative: exact genotype segregation may be implemented for verified parental alleles, while phenotype rules remain conditional or blocked unless the exact literature-supported context is present.

## Nonclaims

The dataset does not support exact SHU, flavor, fruit weight, yield, wall thickness, or climate-adaptation predictions from cultivar names or parental phenotype values.

## Required before production

1. Independent plant geneticist review.
2. Allele-level sequence and marker catalog.
3. Reference assembly/version normalization.
4. Pathogen strain/pathotype interaction registry.
5. Multi-locus mature and immature fruit-color rule curation.
6. Scientific approval and versioning workflow.

All source URLs are included directly in the workbook and CSV source registry.
