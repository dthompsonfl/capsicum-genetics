# V4 Verified Baseline

## Supplied state

The V4 sweep started from the V3 complete archive and the supplied adversarial review bundle. The baseline repository contained **401 files**, **14 forward migrations**, **53 page routes**, **11 API routes**, a pure exact-genetics package, advanced scientific calculation primitives, PostgreSQL RLS/role foundations, a Node worker, Python and R boundaries, and an evidence-bounded research assistant.

The review's P0 findings were confirmed in executable source rather than accepted from narrative alone:

1. Failed sign-in and rate-limit writes could be rolled back with denied transactions.
2. Public idempotency terminal failures were not durably separated from business rollback.
3. Published catalog releases lacked a complete independently reviewed normalized membership graph.
4. Selection plans accepted scientific fields that were not fully persisted.
5. No legitimate frozen dependency graph or clean Node 24 build was present.
6. The default media stack had no path from quarantine to scanner-confirmed acceptance.
7. PostgreSQL authority, concurrency, worker, browser, restore, and deployment evidence remained incomplete.

Additional source defects found during the sweep included unsupported scrypt promisification, public token routes intercepted by authentication middleware, inconsistent scanner configuration names, unsafe browser-visible error/token material, excessive runtime table privileges, missing authentication exports, and an undefined research constant.
