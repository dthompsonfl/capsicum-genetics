# Scientific limitations

The platform provides exact and conditional calculations, not universal biological truth.

## Reliable within explicit assumptions

- diploid, multi-allelic Mendelian segregation from explicit parent genotype hypotheses;
- independent multi-locus products when independence is stated;
- weighted mixtures when parent genotype evidence is unknown or conflicting;
- target-recovery population calculations from the computed probability;
- phased two-locus linkage when phase and recombination inputs are supplied;
- maternal-state transmission when the maternal state is known;
- approved penetrance/rule evaluation within documented applicability;
- deterministic direct Monte Carlo estimates with recorded seed, algorithm version, sample count, and diagnostics.

## Not established by the application

- a cultivar name does not establish genotype;
- phenotype or a photograph does not prove an allele;
- allele capitalization does not prove dominance or function;
- a `Pun1` state does not predict exact Scoville Heat Units;
- disease resistance is not universal across pathogen isolates and environments;
- yield, flavor, maturity, fruit mass, breeding value, G×E, and genomic value require validated quantitative models;
- learned image outputs require a promoted model, model card, dataset provenance, and external evaluation;
- polyploid, aneuploid, apomictic, doubled-haploid, chromosomal-rearrangement, meiotic-drive, pollen-competition, and segregation-distortion systems need separate validated models.

## Current catalog gate

The staged catalog contains 22 loci, 22 evidence claims, and 30 sources. It activates zero executable phenotype rules. All records remain evidence inventory until independent domain review and governed publication.

## Largest scientific risk

The dominant failure mode is incorrect biological identity or unsupported input evidence, not fractional arithmetic. A mathematically exact result is invalid when the accession, seed lot, individual plant, maternal direction, paternal identity, assay, linkage phase, pathogen context, or environment is wrong.
